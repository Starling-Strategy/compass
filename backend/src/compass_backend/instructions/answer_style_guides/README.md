# Compass Answer Style Guides

This folder holds reviewable user-facing answer guidance for Compass.

Answer style guides are product assets. They may shape tone, structure,
caveats, and plain-language explanation after Compass has produced a sealed
answer brief. They must not define data authority. District identity, metric
identity, coverage state, source evidence, and numeric facts remain owned by
the typed Compass pipeline.

## Current Assets

- `default.md` - the active answer-stylist prompt for rewriting a sealed
  deterministic answer brief into clearer markdown.

## Review Rule

Any answer style-guide change should be reviewed with at least one before/after
answer sample and a note describing which answer shape it affects:

- successful data answer
- partial coverage answer
- cannot-answer or clarification answer
- policy-guidance answer
